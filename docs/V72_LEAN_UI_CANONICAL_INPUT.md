# V72 — Lean UI + Canonical Input Contract

Production contract:
- Canonical Input Gate installs before legacy bootstrap.
- Questions must not create task/job/artifact unless explicitly requested.
- Quoted/meta questions are analysis-only.
- Gemini Chief defaults to medium reasoning; question answers default to 1–5 lines.
- Dashboard shows only actionable/non-zero content; completed/cancelled/zero items remain stored but hidden.
- Active Job Cards are capped at 3 on the home workspace.
- No task/history deletion is performed by the lean UI.
